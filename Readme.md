# 📡 NewsAgent

> يجمع أخبار الـ AI كل يوم، يصفيها، يلخصها بأسلوبك، ويرسلها لتيليجرام — بدون ما تحرك إصبع.

---

## الفكرة في جملة وحدة

بدل ما تفتح 10 مواقع كل يوم تدور على الخبر اللي يهمك — **NewsAgent يجيبه إليك، ويشرح ليش يهمك أنت تحديداً.**

---

## شنو يسوي؟

```
RSS Feeds (مصادر أخبار)
        ↓
يجمع الأخبار الجديدة
        ↓
يصفي — يبقي اللي يتعلق بمجالك فقط
        ↓
LLM يلخص كل خبر + يشرح أهميته ليك شخصياً
        ↓
📱 تيليجرام — خبر بخبر، منظم، بالعربي
```

**مثال على رسالة تيليجرام:**

```
📰 خبر جديد في عالم الـ AI

العنوان: OpenAI تطلق نموذج جديد أخف وأسرع

الملخص: نموذج GPT-4o Mini يقدم أداء قريب من GPT-4
بتكلفة أقل بـ 95% — مناسب للتطبيقات اللي تحتاج سرعة.

أهميته ليك: هذا النموذج يفيدك مباشرة في مشروعك
NewsAgent — تقدر تستبدل Ollama بيه للتلخيص وتوفر
وقت المعالجة المحلية...
```

## الهيكل التقني

```
NewsAgent/
├── agent/
│   ├── collector.py          ← يربط كل الخطوات ببعض
│   ├── filter_agent.py       ← يصفي الأخبار بالمواضيع
│   ├── summarizer_agent.py   ← LLM يلخص ويشخصن
│   ├── delivery_agent.py     ← يرسل لتيليجرام
│   └── scheduler_agent.py    ← يشغّل كل شي تلقائياً
├── tools/
│   ├── rss_reader.py         ← يجلب الأخبار من المصادر
│   └── telegram_sender.py    ← يتواصل مع Telegram API
├── config/
│   └── settings.py           ← كل الإعدادات في مكان وحيد
├── graph.py                  ← السكة الحديد (LangGraph)
└── main.py                   ← نقطة البداية الوحيدة
```

## المكتبات المستخدمة

| المكتبة | وظيفتها |
|---------|---------|
| `LangGraph` | يربط الوكلاء ببعض كـ pipeline منظم |
| `LangChain + Ollama` | يشغّل الـ LLM محلياً بدون API |
| `APScheduler` | يشغّل النظام تلقائياً كل يوم |
| `feedparser` | يقرأ RSS Feeds |
| `requests` | يرسل الرسائل لتيليجرام |

## كيف تشغّله

### 1. المتطلبات

```bash
pip install -r requirements.txt
```

تأكد إن Ollama شغّال ومعه الموديل:

```bash
ollama pull qwen3:8b
```

### 2. إعداد المتغيرات

أنشئ ملف `.env`:

```env
TELEGRAM_BOT_TOKEN=your_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
```

### 3. خصّص الملف الشخصي

في `config/settings.py` غيّر `USER_PROFILE` حسب اهتماماتك:

```python
USER_PROFILE = {
    "name": "اسمك",
    "background": "خلفيتك",
    "skills": ["مهاراتك"],
    "current_project": "مشروعك الحالي",
    "goal": "هدفك",
    "learning_path": "مسارك"
}
```

هذا الملف هو اللي يخلي التلخيص **شخصياً ليك** — كلما كان أدق، كلما كان الشرح أفيد.

### 4. شغّل

```bash
python main.py
```

يشتغل فوراً ثم ينتظر وقت التشغيل اليومي تلقائياً.

## قرارات تقنية مهمة

**ليش LangGraph؟**
بدل ما نكتب `collector()` ثم `filter()` ثم `summarize()` يدوياً — LangGraph يديرهم كـ state machine. كل وكيل يأخذ الـ state ويرجعه محدّث. هذا يسهّل إضافة وكيل جديد أو تغيير الترتيب بدون ما نكسر شي.

**ليش Ollama (محلي) بدل OpenAI API؟**
- تكلفة صفر بعد التثبيت
- الخصوصية — أخبارك وملفك الشخصي ما تطلع لخارج
- يشتغل بدون انترنت

**ليش خبر بخبر في تيليجرام بدل رسالة وحدة؟**
تيليجرام يقطع الرسائل الطويلة. رسالة لكل خبر = تنسيق نظيف + تقدر تحذف خبر ما يهمك بدون ما تخسر الباقي.

**ليش `USER_PROFILE` في `settings.py`؟**
مكان وحيد تغيّره وكل النظام يتأثر. لو غيّرت مشروعك أو هدفك — سطر وحيد يكفي.

## الفكرة الكبيرة

معظم أدوات تجميع الأخبار تعطيك **قائمة** — أنت تقرر شنو مهم.

NewsAgent يعطيك **قرار** — يقرأ الخبر، يعرف اهتماماتك، ويقولك "هذا يهمك ليش."

هذا الفرق بين أداة تجمع معلومات وأداة تفكر فيها.
